# FoodKeeper MVP subset

`common_foods.zh-TW.json` is a hand-reviewed, compact subset for the demo. The
storage ranges are transcribed from the English USDA FSIS FoodKeeper data; the
Traditional Chinese names and aliases are project mappings, not USDA
translations. No missing value is inferred.

- Catalog: https://catalog.data.gov/dataset/fsis-foodkeeper-data
- Current English feed: https://www.foodsafety.gov/sites/default/files/foodkeeper_data_url_en.json
- Catalog version date: 2025-01-22
- Retrieved/reviewed: 2026-09-19
- License: CC0-1.0
- Curated JSON SHA-256: `6874b526326cc9f07de79e73e3681ffe16c470aebc62894288f9c3265d68557d`

The current upstream endpoint may reject non-browser downloads with HTTP 403.
For updates, download through an authorized browser, review the English fields,
update only confirmed records, then update the retrieval date and this digest.
Do not treat these quality/storage guidelines as package expiry or a guarantee
of food safety.
